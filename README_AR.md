# موقع تقتني — ملفات المشروع

## نبذة
موقع عربي تعليمي متعدد الصفحات لسوق إلكتروني تجريبي يجمع بين البيع والإيجار ويشجع على إعادة الاستخدام. بُني وفق متطلبات ملف مشروع المقرر والعرض التقديمي المرفقين.

## الصفحات
- `index.html` — الصفحة الرئيسية.
- `products.html` — تصفح المنتجات مع البحث والتصفية والفرز والمفضلة.
- `product-details.html` — تفاصيل كل منتج حسب رقم العرض في الرابط.
- `add-product.html` — إضافة عرض جديد مع التحقق من السعر ونوع العرض، وإظهار فترة الإيجار عند الحاجة، ومعاينة الصورة.
- `how-it-works.html` — خطوات الاستخدام، مقارنة البيع والإيجار، إرشادات الاستخدام المسؤول، والأسئلة الشائعة.
- `about.html` — فكرة المشروع والرؤية والرسالة والهدف وفريق العمل.
- `contact.html` — بيانات التواصل ونموذج توضيحي.

## التشغيل على جهازك
1. فكّي ضغط ملف ZIP.
2. افتحي مجلد `taqtani_final`.
3. افتحي `index.html` في متصفح حديث مثل Chrome أو Edge.
4. للتجربة الأفضل، شغّلي المجلد عبر خادم محلي بسيط باستخدام الأمر التالي من داخل المجلد:

```bash
python -m http.server 8000
```

ثم افتحي `http://localhost:8000`.

## الوظائف التفاعلية
- البحث في الاسم والفئة والوصف.
- التصفية حسب الفئة ونوع العرض.
- ترتيب المنتجات حسب السعر أو الاسم أو الأحدث.
- حفظ المفضلة داخل `localStorage` في المتصفح الحالي.
- إضافة عرض وصورة بعد التحقق من المدخلات.
- ضغط صورة المنتج قبل حفظها لتقليل مساحة التخزين.
- معاينة صورة المنتج وإظهار فترة الإيجار فقط عند اختيار «للإيجار».
- صفحة تفاصيل ديناميكية لكل منتج.
- قائمة تنقل مناسبة لشاشات الجوال.
- تاريخ السنة في تذييل الموقع.

## ملاحظات مهمة عن طبيعة النموذج
- الموقع مشروع تعليمي ثابت ولا يحتوي على خادم خلفي أو قاعدة بيانات مشتركة.
- المنتجات التي يضيفها الزائر والمفضلة تُحفظ في متصفح الجهاز الحالي فقط باستخدام `localStorage`.
- لا توجد عمليات دفع أو حجز أو رسائل معاملات فعلية.
- نموذج التواصل يعرض رسالة تأكيد تجريبية ولا يرسل بريدًا إلكترونيًا. للتواصل الفعلي استخدمي الرابط المباشر `mailto:contact@example.com`.
- البريد `contact@example.com` أُدرج كما زوّدتمونا به.

## نشر الموقع على GitHub Pages
1. سجّلي الدخول إلى GitHub وأنشئي مستودعًا جديدًا باسم `taqtani`.
2. فكّي ضغط ZIP، ثم ارفعي **محتويات المجلد** إلى جذر المستودع (لا ترفعي ملف ZIP وحده).
3. افتحي `Settings` ثم `Pages`.
4. ضمن `Build and deployment` اختاري `Deploy from a branch`.
5. اختاري الفرع `main` والمجلد `/ (root)` ثم اضغطي `Save`.
6. بعد اكتمال النشر سيظهر عنوان الموقع في صفحة Pages، ويكون عادة بصيغة `https://USERNAME.github.io/taqtani/`.

## مراجعة قبل التسليم
- ملف تعليمات المقرر يحدد حجم المجموعة من 3 إلى 5 طلاب. لذلك اعتمد الموقع الأسماء الخمسة الظاهرة في صورة أسماء الفريق: وعد الفهمي، ندى الحارثي، ريوف السواط، رنا المقاطي، ريماس العتيبي.
- شريحة الفريق في العرض التقديمي تضيف اسم جنى الشهراني كعضوة سادسة، وهو اختلاف عن صورة الأسماء وحد المجموعة في التعليمات. يُفضّل مراجعة الشريحة وتصحيحها أو تأكيد إضافة الاسم مع الدكتورة قبل التسليم.
